# CardFlare — Brand

## The logo

The approved CardFlare logo is a circular badge: a charcoal disc holding a
neon-lime playing-card outline with a flare burst and a flame trail.

**Master file:** `public/brand/cardflare-logo.png` (1254 × 1254)

This file is byte-for-byte identical to the approved original. It is never
rewritten — not even losslessly re-encoded, because passing it through an image
pipeline drops colour-profile chunks and is not bit-lossless.

**Do not redesign, reinterpret, redraw, replace, or modify the logo without
explicit approval.**

### Derivatives

Generated by `npm run brand:assets` from the master:

| File                              | Size | Use                                  |
| --------------------------------- | ---- | ------------------------------------ |
| `public/brand/cardflare-mark.png` | 512  | Header, footer, OG image             |
| `src/app/icon.png`                | 256  | Favicon (Next.js generates the rest) |
| `src/app/apple-icon.png`          | 180  | iOS home screen                      |

### ⚠️ One derivative decision needs sign-off

**The supplied master has no transparency.** Every pixel is opaque, and the
circular badge sits on a solid **black square**. On CardFlare's charcoal
background that renders as a visible black box around the mark.

The derivatives therefore apply a circular alpha mask that removes the black
field. **The badge artwork itself is untouched** — same pixels, same colours,
same proportions; only the black corners outside the circle become transparent.

This was treated as a technical fix rather than a redesign so the page could
ship looking correct. **If a transparent-background master is preferred, supply
one and re-run `npm run brand:assets`.** The circle geometry is a single
constant (`CIRCLE`) in `scripts/generate-brand-assets.mjs`.

### Usage rules

- Always pair the mark with the "CardFlare" wordmark unless space forbids it
  (`<Logo markOnly />`).
- Never stretch, recolour, rotate, or add effects to the mark.
- Alt text: the mark is decorative when the wordmark is present
  (`aria-hidden`), and labelled `"CardFlare logo"` when it stands alone. This is
  handled by the `Logo` component — do not hand-roll `<img>` tags for it.

## Typography

- **Sans:** Inter — headings and body.
- **Mono:** JetBrains Mono — reserved for card codes and identifiers.

Both loaded through `next/font` with `display: swap`.

## Voice

Direct, player-to-player, never hype. Short sentences. Say what the product
does, not how revolutionary it is.

- ✅ "CardFlare finds someone at the event who has it."
- ❌ "Revolutionising the way you trade!"

Be honest about stage: the product is being built, not launched. Never imply
CardFlare guarantees a trade, a price, or a card's authenticity.

## Visual direction

Dark charcoal-navy base, muted gray surfaces, faded neon-lime accent used
sparingly for emphasis. Rounded but not bubbly. Subtle glow on primary actions
only. High contrast, generous spacing, restrained motion.

Avoid: heavy gradients, particle effects, casino styling, anything childish.
